# Bubbl — Master Product Specification

**Version:** 1.0  
**Date:** 2026-10-27  
**Author:** Avanti Srihari  

---

## 1. Product Vision

A free mobile SAT prep app that adapts to each student's skill level in real time — just like the real digital SAT. Students answer questions; the app tracks where they're weak and automatically serves harder or easier questions to keep them in the optimal learning zone.

**Core value proposition:**
- Free access for all students (no paywall for core practice)
- Questions aligned to real College Board difficulty (Easy / Medium / Hard / Hardest)
- Adaptive difficulty — get one right, next question is harder
- Gap analysis shows exactly which skills are costing points
- Monetized through ads (free tier) and premium subscription ($9.99/month)

---

## 2. Target Users

**Primary:** High school students (grades 9–12) preparing for the SAT  
**Secondary:** Parents tracking their child's progress  
**Tertiary:** Tutors using it as a diagnostic + practice tool (future B2B)

**Student persona:**  
- 16–18 years old  
- Has taken or is planning to take the SAT 1–3 times  
- Wants targeted practice, not just random questions  
- Uses smartphone 4+ hours/day  
- Free tier user unless parent pays for premium  

---

## 3. Core Features

### 3.1 Adaptive Practice (MVP — must have)
- Student picks: Math or English (or Combined)
- Student picks: domain focus or let the app decide based on gap profile
- App serves questions one at a time
- After each answer: immediate feedback + explanation
- Difficulty adjusts after each answer using ability score
- Session ends at 22 questions (Math) or 27 questions (English) matching real SAT module length

### 3.2 Gap Dashboard (MVP — must have)
- Radar chart showing mastery % across all 9 skill domains
- Overall estimated SAT score range (e.g., 620–680)
- Top 3 weakest skills with drill-down
- "Recommended next practice" button
- Weekly progress trend (last 4 weeks)

### 3.3 Diagnostic Quiz (MVP — must have)
- First-time users take a 10-question diagnostic (2 per domain)
- Sets initial ability score per domain
- Bypasses generic onboarding — goes straight to personalized experience

### 3.4 Gap Analysis Report (MVP — must have)
- Generated by Claude Haiku API after every 3 completed papers
- Natural language explanation of weakness patterns
- Specific actionable advice ("You're missing percent chain questions — practice PSA-04")
- Encouragement + score projection

### 3.5 Question Bank (MVP — must have)
- 5,000 pre-generated questions stored in Supabase
- Never show the same question twice to the same user
- Questions tagged with CB skill code, domain, difficulty rating

### 3.6 Freemium Gating (MVP — must have)
- Free: 2 full papers/week, ads between questions, last 3 attempts only
- Premium: unlimited papers, no ads, full history, PDF download, combined papers

## 6. Platform

- **iOS** (iPhone, iPhone SE and up — min iOS 16)
- **Android** (min Android 10 / API 29)
- Built with React Native (Expo) — single codebase for both

---

## 7. Design Principles

1. **Speed over beauty** — every screen must load in <1 second
2. **One action per screen** — never overwhelm with choices
3. **Instant feedback** — show correct/wrong immediately, never make them wait
4. **Real SAT feel** — question format, wording, and choices must feel authentic
5. **Dark mode by default** — students study at night
6. **No dark patterns** — no fake urgency, no confusing cancel flows

---

## 8. Non-Functional Requirements

| Requirement | Target |
|------------|--------|
| App launch time | < 2 seconds |
| Question load time | < 500ms |
| API response time (paper assembly) | < 1 second |
| Gap analysis response time | < 5 seconds (Claude API) |
| Offline support | Last session viewable offline |
| Crash rate | < 0.1% of sessions |
| Data privacy | COPPA compliant (under-13 guard), FERPA aware |
| Accessibility | WCAG 2.1 AA |

## 9. Monetization Summary

See `docs/07_monetization.md` for full detail.

**Free tier:**
- 2 practice papers per week
- AdMob banner between questions 10 and 11
- AdMob interstitial after paper completion
- Basic gap report (top 3 gaps only)
- Last 3 attempts stored

**Premium — $9.99/month:**
- Unlimited papers
- No ads
- Full gap dashboard (all 9 domains + trends)
- Complete attempt history
- PDF download
- Combined Math + English sessions
- Priority question selection (newest questions first)

**Revenue streams:**
1. Subscriptions (primary) — projected $5K/month at 10K MAU
2. AdMob (secondary) — projected $300–600/month at 10K MAU
